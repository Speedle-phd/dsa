# Talente (Katalog)

source: DSA5 Regelwerk, S. 183–213

## Summary

- All talents are active from the start (FW 0) (S. 25, 50).
- FW cap after creation = highest Eigenschaft of the Probe + 2; during creation it is the EG cap (S. 39).
- Belastung "ja" means the talent check is penalized by Belastung (see [../character/conditions.md](../character/conditions.md)).
- Probe, Belastung and Steigerungskosten are listed with each talent (S. 187).

## Values / formulas

BE: ja / nein; `nein*` = the book gives situational exceptions (e.g. helmets).

## Edge cases

- Applications, new applications, tools, example modifiers, Sammelprobe intervals and critical rules per talent are in `client/src/features/heroes/talentDetails.ts` and `talentCriticalRules` (see [skill-checks.md](skill-checks.md), "Implemented talent rules").
- Book name "Gaukeleien" (the key stays `gaukelei`).

## Code

- `server/src/utils/talentCatalog.ts` — Steigerungsfaktoren (matches this table)
- `client/src/features/heroes/talentCatalog.ts` — Probe, Steigerungsfaktor, Belastung (`maybe` = `nein*` or situational), critical rules, group probes
- `client/src/features/heroes/talentDetails.ts` — S. 188–213 description data
