## Source handling

The uploaded source identifies itself as the 4th revised edition and states that the work is copyrighted by Ulisses Spiele GmbH. This project therefore uses this file as a reference source rather than copying the complete rulebook into the repository.

## Rule implementation convention

Keep rule data (tables) separate from logic and cite the source on one line:

```ts
// source: DSA5 Regelwerk, S. <page>
export const aLevelUpCosts = {
   /* … */
} as Record<string, number>
```

This lets `/review-dsa-rule` check every implementation against the rulebook.
